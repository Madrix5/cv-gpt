# 🇪🇸 CV Interactivo | Interfaz Estilo Asistente de IA

¡Bienvenido al repositorio de mi Currículum Vitae interactivo!

Este proyecto es una aplicación web Frontend de una sola página (Single Page Application) que simula la interfaz de un asistente de Inteligencia Artificial (tipo ChatGPT). Permite a los reclutadores y visitantes explorar mi perfil profesional, experiencia y proyectos mediante una experiencia conversacional dinámica.

> ⚠️ **Aviso de Proyecto en Construcción (WIP):** Este repositorio contiene **exclusivamente el código Frontend** (HTML, CSS y JS). Falta la arquitectura del servidor (código Python/Django) y la Base de Datos (BBDD). El proyecto se encuentra actualmente **en construcción** y el código es susceptible a cambios constantes.

## ✨ Características Principales

* **💬 Interfaz Conversacional:** La información del CV se presenta a través de respuestas animadas simulando que una IA está escribiendo en tiempo real.
* **💾 Historial Local (`localStorage`):** El usuario puede interactuar libremente. Las conversaciones se guardan en la memoria del navegador, permitiendo al usuario retomar o eliminar historiales anteriores.
* **🌗 Modo Oscuro / Claro:** Soporte nativo para cambiar el tema visual de la aplicación con un solo clic.
* **📱 Diseño 100% Responsivo:** Adaptado a dispositivos móviles con un menú lateral colapsable.
* **📬 Formulario Dinámico y Validado:** Formulario de contacto integrado que cambia dinámicamente según el tipo de usuario. Incluye validación de datos en tiempo real mediante Expresiones Regulares (REGEX).

## 🛠️ Tecnologías Utilizadas (Frontend)

* **HTML5:** Estructura semántica (preparado para ser motor de plantillas en Django).
* **CSS3 (Vanilla):** Sistema de variables (`:root`) y Flexbox/Grid para el layout.
* **JavaScript (Vanilla JS):** Gestión del DOM, simulador de tipeo, validación REGEX y POO para gestionar el `localStorage`.

## 🚀 Cómo ejecutarlo localmente

1. Clona este repositorio:

    git clone https://github.com/Madrix5/cv-gpt.git

2. Abre el archivo principal en tu navegador web.
   *(Nota: Al faltar la Base de Datos y el Backend, las etiquetas de Django como {{ }} se mostrarán como texto plano, pero el diseño, las animaciones y la lógica de JS funcionarán perfectamente).*

# 🇬🇧 Interactive CV | AI Assistant Style Interface

Welcome to the repository of my interactive Curriculum Vitae!

This project is a Frontend Single Page Application that simulates the interface of an Artificial Intelligence assistant (like ChatGPT). It allows recruiters and visitors to explore my professional profile, experience, and projects through a dynamic conversational experience.

> ⚠️ **Work in Progress (WIP) Notice:** This repository contains **exclusively the Frontend code** (HTML, CSS, and JS). The server architecture (Python/Django code) and the Database (DB) are missing. The project is currently **under construction** and the code is subject to continuous changes.

## ✨ Main Features

* **💬 Conversational Interface:** CV information is presented through animated responses, simulating an AI typing in real-time.
* **💾 Local History (`localStorage`):** Users can interact freely. Conversations are saved in the browser's memory, allowing users to resume or delete previous chat histories.
* **🌗 Dark / Light Mode:** Native support to switch the visual theme with a single click.
* **📱 100% Responsive Design:** Fully adapted to mobile devices with an off-canvas side menu.
* **📬 Dynamic & Validated Form:** Integrated contact form that changes dynamically based on the user type. Includes real-time data validation using Regular Expressions (REGEX).

## 🛠️ Technologies Used (Frontend)

* **HTML5:** Semantic structure (ready to be used as a Django template).
* **CSS3 (Vanilla):** Variable system (`:root`) and Flexbox/Grid layouts.
* **JavaScript (Vanilla JS):** DOM manipulation, typing simulator, REGEX validation, and OOP for `localStorage` management.

## 🚀 How to run locally

1. Clone this repository:

    git clone https://github.com/Madrix5/cv-gpt.git

2. Open the main file in your web browser.

# 🇩🇪 Interaktiver Lebenslauf | KI-Assistenten-Schnittstelle

Willkommen im Repository meines interaktiven Lebenslaufs!

Dieses Projekt ist eine Frontend-Single-Page-Application, die die Benutzeroberfläche eines KI-Assistenten (ähnlich wie ChatGPT) simuliert. Es ermöglicht Recruitern und Besuchern, mein berufliches Profil, meine Erfahrungen und Projekte in Form eines dynamischen Chats zu erkunden.

> ⚠️ **Hinweis zu laufenden Arbeiten (WIP):** Dieses Repository enthält **ausschließlich den Frontend-Code** (HTML, CSS und JS). Die Serverarchitektur (Python/Django-Code) und die Datenbank (DB) fehlen. Das Projekt befindet sich derzeit **im Aufbau** und der Code kann sich jederzeit ändern.

## ✨ Hauptmerkmale

* **💬 Konversationsschnittstelle:** Die Informationen im Lebenslauf werden durch animierte Antworten präsentiert, die eine in Echtzeit tippende KI simulieren.
* **💾 Lokaler Verlauf (`localStorage`):** Die Nutzer können frei interagieren. Unterhaltungen werden im Speicher des Browsers gespeichert, sodass vorherige Chatverläufe fortgesetzt oder gelöscht werden können.
* **🌗 Dunkel-/Hell-Modus:** Native Unterstützung zum Wechseln des visuellen Designs mit einem einzigen Klick.
* **📱 100% Responsives Design:** Perfekt an mobile Geräte angepasst mit einem einklappbaren Seitenmenü.
* **📬 Dynamisches & validiertes Formular:** Integriertes Kontaktformular, das sich dynamisch je nach Nutzertyp ändert. Enthält eine Datenvalidierung in Echtzeit mittels regulärer Ausdrücke (REGEX).

## 🛠️ Verwendete Technologien (Frontend)

* **HTML5:** Semantische Struktur (vorbereitet als Django-Template).
* **CSS3 (Vanilla):** Variablensystem (`:root`) und Flexbox/Grid-Layouts.
* **JavaScript (Vanilla JS):** DOM-Manipulation, Tipp-Simulator, REGEX-Validierung und OOP für die Verwaltung des `localStorage`.

## 🚀 Lokale Ausführung

1. Klonen Sie dieses Repository:

    git clone https://github.com/Madrix5/cv-gpt.git

2. Öffnen Sie die Hauptdatei in Ihrem Webbrowser.
   *(Hinweis: Da die Datenbank und das Backend fehlen, werden Django-Tags wie {{ }} als Klartext angezeigt, aber das Design, die Animationen und die JS-Logik funktionieren einwandfrei).*
