# 🤖 cv.gpt | Portafolio Interactivo

Este proyecto es una recreación de la interfaz de **ChatGPT** aplicada al currículum personal. El objetivo es ofrecer una experiencia de usuario familiar e interactiva donde se puede "chatear" con el perfil profesional para conocer la experiencia, estudios y proyectos.

> 🚧 **PROYECTO EN CONSTRUCCIÓN** 🚧  
> Este repositorio se encuentra actualmente bajo desarrollo activo. Algunas funcionalidades pueden estar incompletas o en fase de prueba.

---

## 📋 Sobre el Proyecto

La idea principal es transformar el CV estático tradicional en una aplicación web dinámica. En lugar de leer un documento, los reclutadores o interesados pueden interactuar con secciones específicas como:
- **Sobre mí**: Mi historia y motivación.
- **Experiencia**: Trayectoria laboral detallada.
- **Estudios**: Mi formación académica (Ingeniería, Física, 42 Barcelona).
- **Idiomas**: Competencias lingüísticas.

## 🛠️ Tecnologías utilizadas

Para mantener el proyecto ligero, rápido y sin dependencias externas complejas, estoy utilizando:
- **HTML5**: Estructura semántica.
- **CSS3**: Variables personalizadas, Flexbox y animaciones de interfaz (estilo Dark/Light mode).
- **JavaScript (Vanilla)**: Lógica de interacción, manejo de datos de CV y simulación de escritura de la IA.
